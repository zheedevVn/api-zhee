Khu vực Video VIP

Truy cập các cụm media chỉ sau khi xác thực bằng API Key hợp lệ. Nội dung và các nút phát video sẽ không được tải cho đến khi máy chủ xác nhận key.

Nhập API Key để tiếp tục

Key chỉ được giữ trong phiên hiện tại để gọi API. Khi khóa lại hoặc tải lại trang, bạn phải nhập lại.

Ví dụ gọi API

Dùng API Key để mở khóa danh sách media, sau đó chọn cụm máy chủ hoặc truyền ID cụ thể.

GET /video?node=node_v1&key=YOUR_API_KEY

Bảo vệ & phạm vi

Key chỉ nằm trong bộ nhớ phiên hiện tại. Không có key hợp lệ, máy chủ không trả danh sách cluster hoặc link media.

GET /video/images?url=PUBLIC_URL&key=YOUR_API_KEY
